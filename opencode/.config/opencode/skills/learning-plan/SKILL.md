# Learning Plan

## Purpose

Comprehensive route from current knowledge to practical competence.
Typical horizon: one month.
Actual scope: learner goals, baseline, and available time.

## Intake

Existing context first; questions for missing information only.

Required context:
- Topic and motivation
- Desired end capability
- Current knowledge and relevant experience
- Available hours per week
- Deadline or preferred duration
- Practical application or target project
- Constraints: tools, budget, access, prerequisite knowledge

Question budget: up to three focused questions per turn.
No redundant questions or exhaustive intake questionnaire.

Baseline:
- Brief diagnostic task when useful
- Self-reported experience plus demonstrated evidence
- Explicit uncertainty for untested prerequisites

## Topic Map

Topic breakdown:
- Foundational concepts
- Prerequisite relationships
- Core skills
- Common misconceptions
- Practical applications
- Advanced or optional branches

Priority:
- Essential foundations
- High-value capabilities for learner goal
- Supporting knowledge
- Optional depth

Scope tradeoffs:
- Breadth versus depth
- Available time versus target capability
- Necessary prerequisite work
- Explicit exclusions and deferred topics

No promise of topic mastery within arbitrary deadline.

## Plan Design

Default structure: four weeks, with workload appropriate to time budget.
Alternative duration: learner preference or scope requirements.

Each week:
- Theme and rationale
- Observable learning outcomes
- Ordered study blocks
- Practice tasks
- Selected resources
- Review of earlier material
- Milestone assessment
- Estimated effort

Each study block:
- Objective
- Relevant prerequisite
- Reading, explanation, or demonstration
- Active practice
- Concrete output or success evidence
- Approximate duration

Scheduling:
- Realistic workload within stated budget
- Catch-up capacity
- Flexible study blocks unless daily calendar requested
- Rough estimates with assumptions

Progression:
- Foundations before dependent concepts
- Supported practice before independent application
- Increasing integration across topics
- Final task representative of learner goal

## Resources

Source priority:
- Official documentation for tools and APIs
- Established textbooks and courses
- Reputable educational institutions
- Primary sources when relevant

Resource curation:
- Small core set
- Specific chapters, sections, or lessons where available
- Purpose and estimated effort
- Optional references separate from required material
- Free resources by default
- Paid-resource costs and access requirements

Citation basis: verified sources.
Unverified availability or version relevance: explicit uncertainty.

## Required Output

1. Mission and target capability
2. Baseline and prerequisite gaps
3. Topic map and scope
4. Four-week roadmap or agreed alternative
5. Ordered study blocks and workload
6. Practice and milestone criteria
7. Final demonstration or capstone
8. Curated resources
9. Review and catch-up strategy
10. Immediate first step

Detail:
- Comprehensive roadmap
- Actionable first week
- Later-week detail proportional to uncertainty
- No exhaustive syllabus disconnected from learner goal

## Plan Checkpoint

Learner confirmation of:
- Scope
- Workload
- Sequence
- End capability

Revision basis:
- Learner preferences
- Diagnostic evidence
- Available time
- Progress and difficulties

## Progress and Continuity

Progress evidence:
- Learner explanations
- Completed exercises
- Artifacts
- Independent demonstrations

No completion credit from reading alone.

Checkpoint contents:
- Milestone status
- Evidence
- Gaps
- Workload adjustments
- Next study block

Persistent plan: optional, with permission and agreed location.
Default: conversation.

## Relationship to Teach

Plan role: sequence, resources, practice, checkpoints.
Teach role: first-principles explanation of selected concepts.

Handoff context:
- Current milestone
- Target capability
- Relevant prior knowledge
- Known misconception
- Suggested exercise

No automatic full-course lesson generation.
